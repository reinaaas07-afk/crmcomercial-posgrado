Documentación Técnica & Sustentación de Posgrado

Memoria técnica, arquitectura, Modelo Entidad-Relación (ERD) y flujos operacionales de CRMComercial.

🏛 1. Arquitectura del Sistema

CRMComercial es una plataforma cliente-servidor de alto desempeño diseñada específicamente para IB SYSTEM S.R.L. Su arquitectura modular comprende:

  • Frontend: HTML5 semántico, CSS3 con variables nativas de diseño responsivo y JavaScript Vanilla sin dependencias pesadas, optimizado para ejecución instantánea en cualquier navegador.
  • Backend: Node.js con Express.js proporcionando una API RESTful stateless, middleware de auditoría y parsing para JSON y Excel/CSV (SheetJS).
  • Capa de Persistencia: Motor dual con almacenamiento persistente en disco y conexión relacional con MySQL 8.0 gestionado a través de pool de conexiones (`mysql2/promise`).
  • Seguridad & RBAC: Modelo de Control de Acceso Basado en Roles (Administrador General, Supervisor Comercial, Ejecutivo Comercial, Analista Comercial) con auditoría inmutable de IP, fecha y hora.

🚀 3. Casos de Uso y Flujos Operacionales

CU-01
Autenticación y Control de Acceso (RBAC): Cada colaborador ingresa con credenciales privadas. Al cambiar de usuario, la sesión se destruye por completo y se audita con marca de tiempo e IP.
CU-02
Prospección y Relación Empresa-Contacto: Toda empresa creada mantiene la colección de sus contactos. Un contacto no puede existir en el vacío, está formalmente vinculado a su razón social y RNC.
CU-03
Cotización Automática del Pipeline: Al seleccionar un Plan Oficial IB SYSTEM (Básico, PYME, Empresarial, Corporativo) y configurar la cantidad de usuarios por cada módulo específico, el CRM calcula en tiempo real el valor mensual y anual.
CU-04
Importación Masiva Inteligente: Lectura de archivos Excel/CSV con detección heurística de las 12 columnas oficiales de IB SYSTEM, deduplicación de prospectos y generación automática de empresas y decisores.

🗄 4. Estructura de Base de Datos (MySQL 8.0 & JSON)

Esquema normalizado relacional diseñado para alta integridad referencial, trazabilidad inmutable y soporte multiusuario:

usuarios

id (PK), nombre, apellido, email, usuario, password_hash, rol (RBAC), telefono, activo, empresa, subcuenta, fecha_creacion, ultimo_acceso, ultimo_cierre.

empresas

id (PK), razon_social, nombre_comercial, rnc (UNIQUE), direccion, ciudad, provincia, telefono, correo, sitio_web, industria, responsable_comercial, usuario_id (FK), estado_comercial.

contactos

id (PK), nombre, apellido, empresa_id (FK), empresa, cargo, telefono, whatsapp, correo, direccion, ciudad, provincia, naturaleza_negocio, estado_comercial, producto_interes, modulo_principal, responsable_comercial, usuario_id (FK), proximo_seguimiento, notas, etiquetas.

prospectos (Pipeline)

id (PK), empresa_id (FK), empresa, contacto_principal, telefono, whatsapp, correo, canal_captacion, plan_seleccionado, costo_base, modulos_adicionales, costo_adicional, costo_mensual, valor_estimado (anual), cantidad_usuarios, etapa, responsable_comercial, usuario_id (FK), dias_sin_seguimiento.

seguimientos & tareas

id (PK), prospecto_id (FK), canal (Llamada, WhatsApp, Correo, Reunión, Nota), fecha, hora, resultado, observaciones, proxima_accion, fecha_proximo_seguimiento, usuario_id (FK).

auditoria (Inmutable)

id (PK), fecha, hora, usuario, usuario_id, accion (Login, Logout, Creación, Edición, Eliminación, Migración), modulo, registro_afectado, detalles, ip.

⇩ 5. Flujo de Importación Inteligente de Datos

Pipeline de procesamiento de archivos Excel (.xlsx) y CSV externos con validación heurística y deduplicación:

Paso 1
Carga del Archivo: Selección o arrastre de archivo .xlsx o .csv. Decodificación instantánea en memoria mediante SheetJS (XLSX.read).
Paso 2
Mapeo Heurístico Automático: Detección automática de encabezados IB SYSTEM (Empresa, Contacto, Teléfono, Correo, Naturaleza, POS Digital, Certificado FE, Módulos, Estado).
Paso 3
Deduplicación & Validación en Tiempo Real: Cotejo por RNC, correo electrónico y teléfono normalizado contra el padrón activo para prevenir registros duplicados.
Paso 4
Inserción Concurrente y Auditoría: Creación atómica de la Empresa, el Contacto directivo asociado y la Oportunidad en el Pipeline Comercial con registro de auditoría.

📈 6. Flujo del Pipeline Comercial & Ciclo de Conversión

Ciclo de vida de prospectos y conversión comercial para IB SYSTEM S.R.L.:

1. Contacto Inicial

Captación vía importación, web o llamada. Registro de decisor y empresa asociada.

2. Interesado

Demostración técnica de Facturación Electrónica o POS Digital. Calificación de necesidades.

3. Propuesta Enviada

Cotización formal con cálculo automático según plan y cantidad de usuarios por módulo.

4. Cierre Exitoso (Ganado)

Firma de contrato, pase a cliente activo y cálculo del valor anualizado recurrente.

⚡ Motor de Alertas Automáticas: El sistema monitorea la última interacción de cada prospecto y genera alertas a los 3, 5, 7 y 15 días sin seguimiento para evitar fugas comerciales.
